EL PROBLEMA
═══════════

ANTES: Ground truth por TEMA
├─ cubismo   → {doc1, doc2, ..., doc7}       (todos del tema)
├─ barroco   → {doc1, doc2, ..., doc9}       (todos del tema)
└─ PROBLEMA: Cada pregunta se evaluaba contra TODOS los docs del tema
             aunque algunos NO responden esa pregunta específica
             → Recall incorrecto, métricas falsas

AHORA: Ground truth por PREGUNTA
├─ "¿Qué es el cubismo?"      → {El cubismo.txt, cubismo-2.txt, ...}  (4 docs)
├─ "Características del cubismo?" → {El cubismo.txt, cubismo-2.txt, ...}  (4 docs)
├─ "¿Qué es el barroco?"      → {QUE_ES_EL_BARROCO_1.txt, ...}        (4 docs)
└─ BENEFICIO: Cada pregunta se evalúa contra su verdadero ground truth
              → Recall correcto, métricas honestas

IMPACTO EN METRICAS
═══════════════════

F1 scores pueden cambiar (especialmente hacia arriba).
Esto es CORRECTO porque:
- ANTES: GT incorrecto (evaluaba contra todos los docs del tema)
- AHORA: GT correcto (evalúa contra docs relevantes de esa pregunta)

Ejemplo:
  ANTES: F1("¿Qué es el cubismo?") = 0.45
         (comparando contra 7 docs, algunos irrelevantes)
  
  AHORA: F1("¿Qué es el cubismo?") = 0.70
         (comparando contra 4 docs relevantes)

← Métrica más honesta y útil
